Lagos State

Lagos State Physical Planning Permit Authority (LASPPPA)

Typical requirements for a building plan approval:

  • Certificate of Occupancy / Title document
  • Survey plan (registered with the State Surveyor-General)
  • Architectural, structural & M&E drawings sealed by a registered professional
  • Soil investigation / geotechnical report (for storeys above ground+1)
  • EIA report where applicable (see EIA Tools)
  • Tax clearance certificate & development levy payment

Estimated processing time: 30–45 working days. Use the Cost Estimator for current fee schedules.
