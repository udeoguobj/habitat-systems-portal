🔒 End-to-end encrypted
🔒 Messages are encrypted in your browser with AES-GCM using a key derived from an ECDH exchange (Web Crypto API) before being "sent." The mock server (localStorage, standing in for a real backend) only ever stores ciphertext — open your browser's dev tools and inspect localStorage.hs_chat_messages to see it's unreadable. See CHAT-INTEGRATION.md for how to wire this to a real backend + WebSocket relay.
